# 15-SECTION ON-PAGE SEO CHECKLIST

EVERY ARTICLE MUST BE CHECKED AGAINST ALL 15 SECTIONS BELOW.

---

## 1. HEAD & METADATA — What Google indexes first

Implement:

* Title tag: approximately 50–60 characters where practical.
* Primary keyword near the beginning of the title where natural.
* Meta description: approximately 150–160 characters where practical.
* Meta description should include keyword + benefit + soft CTA.
* Canonical URL.
* Open Graph:

  * og:title
  * og:description
  * og:image
  * og:url
  * og:type
* OG image approximately 1200×630.
* Twitter Card:

  * summary_large_image
  * title
  * description
  * image
* `<html lang="en">` or the correct language.
* Responsive viewport meta tag.
* Favicon.
* apple-touch-icon.
* UTF-8 charset.

Do not create duplicate metadata.

---

# 2. URL STRUCTURE — Clean, readable, keyword-forward

Use:

* Short slug.
* Prefer under 60 characters where practical.
* Primary keyword in the slug where natural.
* Lowercase URLs.
* Hyphens only.
* Never use underscores.
* Avoid unnecessary stop words such as "the", "a", "of".
* Keep URLs logically structured.

Examples:

`/blog/[slug]`

or

`/services/[slug]`

Do not change an existing URL unnecessarily if doing so would create SEO problems.

---

# 3. HEADINGS — Structure for users and search engines

Requirements:

* Exactly ONE H1 per page.
* H1 should contain the primary topic/keyword naturally.
* Logical H2 → H3 hierarchy.
* Never skip heading levels unnecessarily.
* H2s should cover supporting keywords and important questions.
* Use natural language.
* Do NOT keyword stuff headings.

---

# 4. COPY & BODY — Answer the query quickly

Requirements:

* Primary keyword within the first 100 words.
* Direct answer to the main query in the first paragraph.
* Match search intent.
* Article length should be informed by SERP research.
* Aim for approximately the top-3 average length ±20% when appropriate.
* Use short paragraphs.
* Prefer 1–4 sentence paragraphs.
* Target approximately 8th–10th grade readability unless the subject requires technical depth.
* Prefer active voice.
* Bold important phrases sparingly.
* Use bullets where appropriate.
* Use numbered lists where appropriate.
* Include tables when they improve comprehension.
* Avoid filler.
* Avoid repetition.
* Avoid keyword stuffing.

The article should be genuinely useful even if the reader never becomes a customer.

---
